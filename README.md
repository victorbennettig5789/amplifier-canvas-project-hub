## Overview

Amplifier Canvas is an HTML-based workspace that gathers project details and session activity into a single browser interface. The project dashboard gives users an immediate view of session conditions, including work that is running, finished, waiting, or stuck.

Alongside project and session navigation, the workspace includes file browsing, document display, source-code inspection, image previews, and terminal integration. Because it is provided as a self-contained HTML/CSS prototype, Amplifier Canvas offers a compact way to explore project and session management workflows without depending on a separate desktop application.

## Included Capabilities

- Project dashboard showing the state of current sessions
- Separate status indicators for running, done, waiting, and stuck work
- Navigation across multiple projects and sessions
- File browser with previews for documents and assets
- Rendered Markdown for project documentation and notes
- Syntax highlighting for source-code previews
- Built-in image previews
- Embedded terminal area
- Self-contained HTML/CSS prototype layout

## Using the Workspace

The basic workflow is:

1. Launch Amplifier Canvas in a browser.
2. Select a project from the project section.
3. Examine the session summary to locate running, completed, waiting, or stuck work.
4. Move between sessions to review their current context.
5. Open project files through the file panel.
6. Inspect Markdown, source files, and images using the available previews.
7. Use the embedded terminal area for terminal-connected tasks.
8. Change projects without leaving the workspace.

For a simple local test, open the primary HTML entry point from the cloned repository in your browser.
